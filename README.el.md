# UOI SSO WordPress Plugin

Το πρόσθετο UOI SSO επιτρέπει την αυθεντικοποίηση χρηστών σε ιστοτόπους WordPress χρησιμοποιώντας την υπηρεσία CAS (Central Authentication Service) του Πανεπιστημίου Ιωαννίνων.

## Χαρακτηριστικά

*   **Αυθεντικοποίηση CAS**: Ασφαλής σύνδεση μέσω του sso.uoi.gr.
*   **Αντιστοίχιση Ιδιοτήτων**: Αυτόματη ενημέρωση στοιχείων χρήστη (Όνομα, Επώνυμο, Email) από το CAS.
*   **Αντιστοίχιση Ρόλων**: Αυτόματη ανάθεση ρόλων WordPress (π.χ. Συνδρομητής, Συντάκτης) βάσει ιδιοτήτων του χρήστη στο CAS (π.χ. φοιτητής, μέλος ΔΕΠ).
*   **Τοπικοποίηση**: Πλήρως μεταφρασμένο στα Ελληνικά.
*   **Εύκολη Ρύθμιση**: Διαχειριστικό περιβάλλον για όλες τις ρυθμίσεις.

## Εγκατάσταση

1.  Κατεβάστε την τελευταία έκδοση από τις "Εκδόσεις" (Releases) στο GitHub.
2.  Στο διαχειριστικό του WordPress, πηγαίνετε στα **Πρόσθετα > Προσθήκη Νέου**.
3.  Επιλέξτε **Μεταφόρτωση Προσθέτου** και ανεβάστε το αρχείο .zip.
4.  Ενεργοποιήστε το πρόσθετο.

## Ρύθμιση

Μετά την ενεργοποίηση, πηγαίνετε στις **Ρυθμίσεις > UOI SSO**.

### Ρυθμίσεις CAS
*   **URL Διακομιστή**: sso.uoi.gr
*   **Θύρα**: 443
*   **Πλαίσιο (Context)**: /cas

### Αντιστοίχιση Ιδιοτήτων
Ορίστε τα ονόματα των πεδίων που επιστρέφει το CAS για να ενημερώνονται τα αντίστοιχα πεδία στο WordPress:
*   **Όνομα**: givenName
*   **Επώνυμο**: sn
*   **Email**: mail

### Αντιστοίχιση Ρόλων
Μπορείτε να ορίσετε κανόνες για το ποιο ρόλο θα παίρνουν οι χρήστες ανάλογα με την ιδιότητά τους (π.χ. eduPersonAffiliation).

**Μορφή**: `τιμή_cas:ρόλος_wordpress`

**Παράδειγμα**:
```text
student:subscriber
teacher:editor
staff:author
```

## Χρήση

Το κουμπί "Σύνδεση στο Π.Ι." εμφανίζεται αυτόματα στη σελίδα σύνδεσης του WordPress (`wp-login.php`).

Εάν θέλετε να το προσθέσετε σε άλλη σελίδα, χρησιμοποιήστε το shortcode:
`[uoi_sso_button]`

## Απαιτήσεις

*   WordPress 6.0 ή νεότερο
*   PHP 8.0 ή νεότερο
*   Επέκταση OpenSSL ενεργοποιημένη στον διακομιστή
