# UOI SSO WordPress Plugin

Το πρόσθετο UOI SSO επιτρέπει την αυθεντικοποίηση χρηστών σε ιστοτόπους WordPress χρησιμοποιώντας την υπηρεσία CAS (Central Authentication Service) του Πανεπιστημίου Ιωαννίνων.

## Τεκμηρίωση

Για πλήρεις οδηγίες εγκατάστασης, ρύθμισης και χρήσης, παρακαλούμε επισκεφθείτε τα docs:

👉 **[Διαβάστε τα Docs](https://vrallis.github.io/uoi-sso-wordpress/el/)**

## Χαρακτηριστικά

*   **Αυθεντικοποίηση CAS**: Ασφαλής σύνδεση μέσω του sso.uoi.gr.
*   **Αντιστοίχιση Ιδιοτήτων**: Αυτόματη ενημέρωση στοιχείων χρήστη.
*   **Αντιστοίχιση Ρόλων**: Αυτόματη ανάθεση ρόλων WordPress.
