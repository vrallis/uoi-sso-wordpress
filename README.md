# UOI SSO WordPress Plugin

[Διαβάστε στα Ελληνικά](README.el.md)

The UOI SSO plugin enables user authentication on WordPress sites using the University of Ioannina's CAS (Central Authentication Service).

## Documentation

For full installation, configuration, and usage instructions, please visit the documentation:

👉 **[Read the Documentation](https://vrallis.github.io/uoi-sso-wordpress/)**

## Features

*   **CAS Authentication**: Secure login via sso.uoi.gr.
*   **Attribute Mapping**: Automatic user data updates.
*   **Role Mapping**: Automatic WordPress role assignment.
*   **CSRF & Replay Protection**: State tokens and single-use tickets.
*   **Single Logout (SLO)**: WordPress logout triggers CAS logout.
*   **Redirect Preservation**: Users return to their original page after login.
*   **Clean Uninstall**: All plugin data removed on delete.
*   **Accessibility**: ARIA attributes on the SSO button.
*   **Localization**: Fully localized in English and Greek.
