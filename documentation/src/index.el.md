# UOI SSO WordPress Plugin

Καλώς ήρθατε στην τεκμηρίωση για το **Πρόσθετο UOI SSO WordPress**.

Αυτό το πρόσθετο παρέχει μια απρόσκοπτη εμπειρία Ενιαίας Εισόδου (SSO) για το [Πανεπιστήμιο Ιωαννίνων](https://www.uoi.gr) χρησιμοποιώντας το πρωτόκολλο CAS.

## Χαρακτηριστικά

*   **Πιστοποίηση CAS**: Ασφαλής σύνδεση χρηστών μέσω `sso.uoi.gr`.
*   **Αντιστοίχιση Ιδιοτήτων**: Αντιστοίχιση ιδιοτήτων CAS (π.χ. `givenName`, `sn`) σε πεδία χρηστών του WordPress.
*   **Αντιστοίχιση Ρόλων**: Αυτόματη ανάθεση ρόλων WordPress (π.χ. Συνδρομητής, Συντάκτης) με βάση τους ρόλους CAS (π.χ. Φοιτητής, Καθηγητής).
*   **Τοπικοποίηση**: Πλήρως μεταφρασμένο περιβάλλον στα Αγγλικά και Ελληνικά.
*   **Φιλικό προς Προγραμματιστές**: Επεκτάσιμη αρχιτεκτονική με hooks και filters.
