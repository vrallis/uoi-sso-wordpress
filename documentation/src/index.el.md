# UOI SSO WordPress Plugin

Καλώς ήρθατε στην τεκμηρίωση για το **Πρόσθετο UOI SSO WordPress**.

Αυτό το πρόσθετο παρέχει μια απρόσκοπτη εμπειρία Ενιαίας Εισόδου (SSO) για το [Πανεπιστήμιο Ιωαννίνων](https://www.uoi.gr) χρησιμοποιώντας το πρωτόκολλο CAS.

## Χαρακτηριστικά

*   **Πιστοποίηση CAS**: Ασφαλής σύνδεση χρηστών μέσω `sso.uoi.gr`.
*   **Αντιστοίχιση Ιδιοτήτων**: Αντιστοίχιση ιδιοτήτων CAS (π.χ. `givenName`, `sn`) σε πεδία χρηστών του WordPress.
*   **Αντιστοίχιση Ρόλων**: Αυτόματη ανάθεση ρόλων WordPress (π.χ. Συνδρομητής, Συντάκτης) με βάση τους ρόλους CAS (π.χ. Φοιτητής, Καθηγητής).
*   **Προστασία CSRF**: Tokens κατάστασης αποτρέπουν επιθέσεις cross-site request forgery κατά τη ροή SSO.
*   **Πρόληψη Επανάληψης Εισιτηρίων**: Κάθε εισιτήριο CAS μπορεί να χρησιμοποιηθεί μόνο μία φορά.
*   **Ενιαία Αποσύνδεση (SLO)**: Η αποσύνδεση από το WordPress αποσυνδέει και από τον διακομιστή CAS.
*   **Διατήρηση Ανακατεύθυνσης**: Η παράμετρος `redirect_to` διατηρείται κατά τη ροή SSO.
*   **Διαχείριση Συγκρούσεων Email**: Αποτρέπει την κατάληψη λογαριασμού όταν ένα email CAS ανήκει σε διαφορετικό χρήστη.
*   **Επικύρωση Εισόδων**: Όλες οι ρυθμίσεις διαχειριστή ελέγχονται με αυστηρή επικύρωση (εύρος θύρας, μορφή ρόλων, μορφή URL).
*   **Προσβασιμότητα**: Το κουμπί SSO περιλαμβάνει ιδιότητες ARIA για αναγνώστες οθόνης.
*   **Καθαρή Απεγκατάσταση**: Όλα τα δεδομένα του προσθέτου (επιλογές και transients) αφαιρούνται κατά τη διαγραφή.
*   **Τοπικοποίηση**: Πλήρως μεταφρασμένο περιβάλλον στα Αγγλικά και Ελληνικά.
*   **Φιλικό προς Προγραμματιστές**: Επεκτάσιμη αρχιτεκτονική με διεπαφή παρόχου και το φίλτρο `uoi_sso_auth_provider`.
