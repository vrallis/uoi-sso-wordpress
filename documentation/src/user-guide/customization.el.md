# Προσαρμογή

## Το Κουμπί "Σύνδεση στο Π.Ι."

Από προεπιλογή, το πρόσθετο προσθέτει αυτόματα το κουμπί "Σύνδεση στο Π.Ι." στην τυπική φόρμα σύνδεσης του WordPress (`/wp-login.php`).

### Προσαρμοσμένη Τοποθέτηση (Shortcode)

Εάν χρησιμοποιείτε μια προσαρμοσμένη σελίδα σύνδεσης ή θέλετε να τοποθετήσετε το κουμπί αλλού (π.χ. σε ένα widget πλευρικής στήλης), χρησιμοποιήστε το shortcode:

```
[uoi_sso_button]
```

### Στυλ

Το κουμπί χρησιμοποιεί τις τυπικές κλάσεις κουμπιών του WordPress (`button button-primary button-large`). Μπορείτε να παρακάμψετε τα στυλ στο CSS του θέματός σας ή στον Προσαρμογέα (Customizer).

Το πρόσθετο φορτώνει το δικό του stylesheet (`public/css/uoi-sso-public.css`) και script (`public/js/uoi-sso-public.js`) μόνο στη σελίδα σύνδεσης.

**Επιλογέας CSS:**
```css
.uoi-sso-container .button {
    /* Τα προσαρμοσμένα στυλ σας εδώ */
    background-color: #0055a5;
}
```

### Προσβασιμότητα

Το κουμπί SSO περιλαμβάνει ιδιότητες ARIA για αναγνώστες οθόνης:

*   `role="complementary"` στο container
*   `aria-label="Ενιαία Είσοδος"` στο container
*   `aria-label="Σύνδεση με τον λογαριασμό σας στο Πανεπιστήμιο Ιωαννίνων"` στον σύνδεσμο
*   `role="button"` στον σύνδεσμο

## Ενιαία Αποσύνδεση (SLO)

Όταν ένας χρήστης αποσυνδέεται από το WordPress, ανακατευθύνεται αυτόματα μέσω του endpoint αποσύνδεσης του διακομιστή CAS. Αυτό εξασφαλίζει ότι η συνεδρία SSO του χρήστη τερματίζεται σε όλες τις εφαρμογές που χρησιμοποιούν CAS.

Δεν απαιτείται πρόσθετη ρύθμιση — η SLO είναι ενεργοποιημένη από προεπιλογή.

## Προσαρμοσμένος Πάροχος Πιστοποίησης

Η αρχιτεκτονική του προσθέτου υποστηρίζει αντικατάσταση του παρόχου CAS με μια προσαρμοσμένη υλοποίηση μέσω του φίλτρου `uoi_sso_auth_provider`. Δείτε τη σελίδα [Hooks & Filters](../developer-guide/hooks.md) για λεπτομέρειες.
