# Προσαρμογή

## Το Κουμπί "Σύνδεση στο Π.Ι."

Από προεπιλογή, το πρόσθετο προσθέτει αυτόματα το κουμπί "Σύνδεση στο Π.Ι." στην τυπική φόρμα σύνδεσης του WordPress (`/wp-login.php`).

### Προσαρμοσμένη Τοποθέτηση (Shortcode)

Εάν χρησιμοποιείτε μια προσαρμοσμένη σελίδα σύνδεσης ή θέλετε να τοποθετήσετε το κουμπί αλλού (π.χ. σε ένα widget πλευρικής στήλης), χρησιμοποιήστε το shortcode:

```
[uoi_sso_button]
```

### Στυλ

Το κουμπί χρησιμοποιεί τις τυπικές κλάσεις κουμπιών του WordPress (`button button-primary button-large`). Μπορείτε να παρακάμψετε τα στυλ στο CSS του θέματός σας ή στον Προσαρμογέα (Customizer).

**Επιλογέας CSS:**
```css
.uoi-sso-container .button {
    /* Τα προσαρμοσμένα στυλ σας εδώ */
    background-color: #0055a5;
}
```
