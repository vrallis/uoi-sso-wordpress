# Ρύθμιση

Μετά την ενεργοποίηση του προσθέτου, πλοηγηθείτε στο **Ρυθμίσεις > UOI SSO** για να ρυθμίσετε το πρόσθετο.

## Ρυθμίσεις CAS

Αυτές οι ρυθμίσεις συνδέουν τον ιστότοπό σας WordPress με τον διακομιστή CAS του Πανεπιστημίου.

*   **URL Διακομιστή CAS**: Το όνομα κεντρικού υπολογιστή του διακομιστή CAS. Προεπιλογή: `sso.uoi.gr`. Πρέπει να είναι έγκυρη μορφή URL.
*   **Θύρα Διακομιστή CAS**: Ο αριθμός θύρας. Προεπιλογή: `443` (HTTPS). Πρέπει να είναι μεταξύ 1 και 65535· μη έγκυρες τιμές επανέρχονται στο 443.
*   **Πλαίσιο CAS (Context)**: Η διαδρομή URI προς την εφαρμογή CAS. Προεπιλογή: `/cas`.

## Αντιστοίχιση Ιδιοτήτων

Αντιστοιχίστε δεδομένα από την απάντηση CAS σε πεδία προφίλ χρηστών του WordPress.

*   **Ιδιότητα Ονόματος**: Η ιδιότητα CAS για το όνομα του χρήστη. Προεπιλογή: `givenName`.
*   **Ιδιότητα Επωνύμου**: Η ιδιότητα CAS για το επώνυμο του χρήστη. Προεπιλογή: `sn`.
*   **Ιδιότητα Email**: Η ιδιότητα CAS για τη διεύθυνση email του χρήστη. Προεπιλογή: `mail`.

!!! tip "Εύρεση Ιδιοτήτων"
    Εάν δεν είστε σίγουροι για τα ονόματα των ιδιοτήτων, ζητήστε από τον διαχειριστή CAS μια λίστα με τις διαθέσιμες ιδιότητες ή ελέγξτε τα δικά σας δεδομένα προφίλ στο [sso.uoi.gr](https://sso.uoi.gr).

## Αντιστοίχιση Ρόλων

Ελέγξτε ποιος ρόλος ανατίθεται στους χρήστες όταν συνδέονται.

*   **Ιδιότητα Ρόλου**: Η ιδιότητα CAS που καθορίζει τον ρόλο ή την ιδιότητα του χρήστη. Προεπιλογή: `eduPersonAffiliation`.
*   **Κανόνες Αντιστοίχισης**: Καθορίστε πώς οι τιμές CAS αντιστοιχούν σε ρόλους WordPress.
    *   Μορφή: `cas_value:wordpress_role`
    *   Ένας κανόνας ανά γραμμή.
    *   Κάθε κανόνας επικυρώνεται: ο `wordpress_role` πρέπει να είναι ρόλος που υπάρχει στην εγκατάσταση WordPress σας (π.χ. `subscriber`, `editor`, `author`, `administrator`). Μη έγκυροι κανόνες απορρίπτονται σιωπηλά κατά την αποθήκευση.

**Παράδειγμα:**
```text
student:subscriber
teacher:editor
staff:author
```

*   **Λογική**: Το πρόσθετο ελέγχει εάν η `Ιδιότητα Ρόλου` του χρήστη περιέχει την `cas_value`. Εάν ταιριάζει, στον χρήστη ανατίθεται ο αντίστοιχος `wordpress_role`.
*   **Προεπιλογή**: Εάν δεν βρεθεί αντιστοιχία, στον χρήστη ανατίθεται ο ρόλος `subscriber` (Συνδρομητής).

## Τοπικοποίηση (Localization)

Το πρόσθετο εντοπίζει αυτόματα τη γλώσσα του ιστότοπού σας WordPress (όπως έχει οριστεί στο **Ρυθμίσεις > Γενικά > Γλώσσα Ιστότοπου**).

*   **Υποστηριζόμενες Γλώσσες**: Αγγλικά (προεπιλογή), Ελληνικά.
*   **Εναλλακτική (Fallback)**: Εάν ο ιστότοπός σας χρησιμοποιεί μια γλώσσα που δεν υποστηρίζεται, το πρόσθετο θα εμφανίζεται στα **Αγγλικά**.
