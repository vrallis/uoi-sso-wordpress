# Εγκατάσταση

## Απαιτήσεις

*   WordPress 6.0 ή νεότερο
*   PHP 8.0 ή νεότερο
*   Ενεργοποιημένη επέκταση OpenSSL (για ασφαλή επικοινωνία CAS)

## Μέθοδοι Εγκατάστασης

### Επιλογή 1: Μεταφόρτωση μέσω Διαχειριστή WordPress

1.  Κατεβάστε το τελευταίο αρχείο `.zip` από τις [Εκδόσεις GitHub](https://github.com/vrallis/uoi-sso-wordpress/releases).
2.  Συνδεθείτε στον Πίνακα Ελέγχου του WordPress.
3.  Πλοηγηθείτε στο **Πρόσθετα > Προσθήκη Πρόσθετου**.
4.  Κάντε κλικ στο **Μεταφόρτωση Προσθέτου** στην κορυφή.
5.  Επιλέξτε το αρχείο `.zip` και κάντε κλικ στο **Εγκατάσταση Τώρα**.
6.  Κάντε κλικ στο **Ενεργοποίηση Προσθέτου**.

### Επιλογή 2: Χειροκίνητη Εγκατάσταση (FTP/SFTP)

1.  Αποσυμπιέστε το αρχείο του προσθέτου.
2.  Ανεβάστε τον φάκελο `uoi-sso` στον κατάλογο `wp-content/plugins/` του διακομιστή σας.
3.  Συνδεθείτε στον Πίνακα Ελέγχου του WordPress.
4.  Πλοηγηθείτε στα **Πρόσθετα**.
5.  Εντοπίστε το **UOI SSO** και κάντε κλικ στο **Ενεργοποίηση**.

## Ενημερώσεις

### Επιλογή 1: Μεταφόρτωση μέσω Διαχειριστή WordPress (Συνιστάται)

1.  Κατεβάστε το αρχείο `.zip` της νέας έκδοσης.
2.  Πλοηγηθείτε στο **Πρόσθετα > Προσθήκη Πρόσθετου**.
3.  Κάντε κλικ στο **Μεταφόρτωση Προσθέτου**.
4.  Επιλέξτε το νέο αρχείο `.zip` και κάντε κλικ στο **Εγκατάσταση Τώρα**.
5.  Το WordPress θα εντοπίσει το υπάρχον πρόσθετο. Κάντε κλικ στο **Αντικατάσταση τρέχοντος με το μεταφορτωμένο**.

### Επιλογή 2: Χειροκίνητη Ενημέρωση (FTP/SFTP)

1.  Αποσυμπιέστε το αρχείο του νέου προσθέτου.
2.  Συνδεθείτε στον διακομιστή σας μέσω FTP/SFTP.
3.  Αντικαταστήστε τον υπάρχοντα φάκελο `uoi-sso` στον κατάλογο `wp-content/plugins/` με τον νέο.

!!! note "Διατήρηση Ρυθμίσεων"
    Οι ρυθμίσεις σας αποθηκεύονται στη βάση δεδομένων και **θα διατηρηθούν** κατά τις ενημερώσεις.
